# Majorway · 전공에서 시작하는 전국 채용 탐색

Node.js 22 이상에서 별도 패키지 설치 없이 실행합니다. 로컬 실행과 Vercel 배포를 지원합니다.

서비스 주소: https://majorway.vercel.app/

GitHub Pages 주소 https://ljg9809-dotcom.github.io/majorway/ 는 현재 Pages 설정인 `main /docs`의 `docs/index.html`을 통해 Vercel 서비스로 자동 이동합니다. Pages를 루트로 바꾸는 경우에도 같은 동작을 하도록 루트 `index.html`을 함께 유지합니다. 두 위치의 `.nojekyll`은 정적 HTML을 그대로 제공합니다. 실제 화면과 서버 API는 Vercel에서 함께 제공합니다. GitHub 저장소에 API 인증키를 올리지 않습니다.

Vercel 배포는 `vercel.json`을 사용합니다. 브라우저용 세 파일만 `dist/`로 준비하고 `/api/*` 요청을 `api/index.js`의 서버 함수로 연결합니다. 서버가 참조하는 학과 JSON을 함수에 포함하며 `.env`와 원본 압축본은 배포 대상에서 제외합니다. 환경 변수 `BUSAN_API_KEY`(잡알리오 공공기관 채용정보 키), `UNIVERSITY_API_KEY`(대학 학과정보 키)를 Vercel 프로젝트 Production 환경에 등록한 뒤 배포하세요. 선택적으로 `ALIO_API_KEY`를 등록하면 잡알리오 키로 우선 사용합니다. 예전 `WORK24_API_KEY`는 현재 채용 검색에 사용하지 않습니다. 저장소에 연결된 자동 배포를 이용하면 main 브랜치 푸시로 변경 사항이 반영됩니다.

## 1. 키 없이 미리 보기

프로젝트 폴더에서 `node server.mjs`를 실행하고 http://localhost:3000 에 접속하세요. 키가 없으면 가상 공고임을 표시하는 예시 모드로 시작합니다. 실제 API 연결 실패 시 가상 공고로 바꿔 보여주지 않습니다.

## 2. 내 터미널에서 키 등록

서버를 Ctrl+C로 종료한 후 **본인의 PowerShell 터미널**에서 실행하세요.

```powershell
cd 'C:\Users\user\Desktop\공공API서비스'
powershell -NoProfile -ExecutionPolicy Bypass -File .\register-key.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File .\start.ps1
```

등록 스크립트는 입력을 숨기며 클립보드나 명령 인자로 키를 받지 않습니다. 공공데이터포털의 재정경제부_공공기관 채용정보 조회서비스 활용신청이 승인된 인증키를 입력하세요. Decoding 키와 인코딩된 키를 지원합니다. 고용24 키는 사용할 수 없습니다. `.env`의 다른 설정 및 주석을 유지하며 BUSAN_API_KEY 항목만 갱신합니다. 실행 정책 Bypass는 해당 프로세스에만 적용됩니다. 기존 BUSAN_API_KEY 환경 변수가 있다면 Node 환경 변수 우선 규칙에 따라 그 값이 사용됩니다.

키를 넣은 뒤 서버를 다시 시작하고 웹페이지를 새로고침하세요. 실제 공고 모드로 시작합니다. 설정 여부만 브라우저에 전달하며 키 값은 전달하지 않습니다. `.env`는 일반 텍스트 파일이므로 본인 계정에서 관리하고 공유하지 마세요. `.gitignore`는 Git에 새로 포함되는 것을 막으며 이미 추적 중인 파일을 자동 해제하지는 않습니다.

## 데이터 범위와 한계

출처: 잡알리오 공공기관 채용정보

공식 명세: https://www.data.go.kr/data/15125273/openapi.do

API: https://apis.data.go.kr/1051000/recruitment/list

서버가 serviceKey, pageNo, numOfRows=100으로 JSON을 요청하고 시·도 선택 시 공식 workRgnLst 코드를 추가합니다(예: 부산 R3014, 서울 R3010). 전국 선택 시 근무지 코드를 생략합니다. 최대 5페이지(500건)를 조회하고 공시일련번호로 중복 제거합니다. 5분 메모리 캐시와 동시 요청 합치기를 사용합니다. 인증키는 ALIO_API_KEY가 있으면 우선 사용하고, 없으면 기존 BUSAN_API_KEY를 사용합니다. WORK24_API_KEY는 이 서비스에 전송하지 않습니다. 인증 또는 원천 연결 실패 시 예시 공고로 대체하지 않습니다.

공고 제목(recrutPbancTtl), NCS 분야(ncsCdNmLst), 지원 자격·전형 절차 등 제공된 내용을 전공별 키워드와 비교합니다. 전공 자격 판정은 아니며 원문으로 확인해야 합니다. 근무지역(workRgnNmLst)에 국내 지역이 명시된 공고만 표시합니다. 기관 주소를 근무지로 추정하지 않으며 시·도까지만 제공되면 구·동 정보는 미제공으로 유지합니다. 이 경우 세부 지역 선택 시 상세 지역 미제공 포함 옵션으로 함께 볼 수 있습니다.

신입·경력·신입+경력은 공식 recrutSe 코드(R2010/R2020/R2030)로 분류합니다. 고용형태는 hireTypeLst 코드로 정규직(R1010), 무기계약직(R1030), 비정규직(R1040), 청년인턴(R1060/R1070)을 분류합니다. 비정규직은 서비스의 계약직·비정규직 필터에 묶으며 정확한 계약 조건은 원문을 확인합니다. 한 공고의 복수 채용형태를 유지합니다. 공고 시작·종료일과 진행 여부(ongoingYn)를 확인하며 종료된 공고를 접수 중으로 표시하지 않습니다.

개별 원문은 숫자 공시일련번호로 잡알리오 공식 recruitview.do 링크를 구성합니다. 출처가 불명확한 srcUrl을 그대로 브라우저에 전달하지 않습니다. 전체 건수·응답 건수·중복 제거 건수·일부 조회 여부를 구분합니다. 잡알리오 범위의 공공기관 공고이며 민간기업이나 지자체 채용 전체를 제공한다고 주장하지 않습니다. 이전 부산 API와 고용24는 현재 검색 경로에 사용하지 않습니다.

## 키 보호 구조

브라우저 → 로컬 `/api/jobs` → 고정된 공공 API 주소. 서버는 127.0.0.1에만 바인딩합니다. 공개 파일은 세 경로만 허용하며 `.env`, 서버 소스, 등록 스크립트를 제공하지 않습니다. 서버는 요청 URL·키·상위 오류·응답 원문을 로그에 기록하지 않습니다. 응답은 허용된 필드만 정규화하고 키와 인증 파라미터를 제거합니다. 외부 응답 HTML은 실행하지 않고 텍스트로 표시합니다. API 응답 오류 시 상세 원문 대신 일반 안내만 반환합니다. 키는 외부 공공 API의 필수 요청에만 포함됩니다.

## 전국 지역·경력·고용 형태 필터

시·도 → 시·군·구 → 읍·면·동 순서의 종속 선택을 제공합니다. 시·도 선택 시 시·군·구와 읍·면·동을 초기화하며, 시·군·구 변경 시 읍·면·동을 초기화합니다. 기본은 전국이며 시·도를 선택하면 잡알리오 원천 요청도 해당 시·도로 좁힙니다. 캐시는 API 키·시도별로 구분하여 다른 지역 데이터가 섞이지 않습니다.

지역 선택지는 행정표준코드관리시스템의 현존 법정동 전체자료를 정리한 data/regions.json을 사용합니다. 리는 제외하고 시·도, 시·군·구, 읍·면·동만 제공합니다. 시와 일반구는 예를 들어 수원시 장안구처럼 함께 표시하고, 시군구가 없는 세종은 구분 없음으로 처리합니다. 원본 data/regions-source.zip은 검증용으로 보관하며 서버 공개 경로와 Vercel 배포 대상에서는 제외합니다. 지역 자료 출처·조회일·건수는 catalog 응답에 포함됩니다. 갱신은 powershell -NoProfile -ExecutionPolicy Bypass -File ./scripts/update-regions.ps1로 수행합니다.

공고에는 명시된 근무지역만 사용하며 기관 주소·접수처·본문 주소로 상세 근무지를 추정하지 않습니다. 국내 시·도를 확인할 수 없는 값과 해외 근무만 적힌 공고는 제외합니다. 동명이 같은 강서구 등은 소속 시·도와 함께 검증하고 복수 근무지의 시·도/시·군·구/읍·면·동 쌍을 유지합니다. 법정동과 행정동은 서로 자동 변환하지 않습니다. 현재 원천의 통합·특별자치 지역 명칭과 이전 명칭은 같은 시·도 범위로 인식합니다.

잡알리오가 시·도까지만 제공한 공고는 하위 지역 선택 시 기본적으로 제외합니다. 상세 지역 미제공 포함 옵션은 선택한 시·도 안에서만 누락된 하위 정보를 허용하며, 다른 시·도 또는 명시된 다른 구·군으로 확장하지 않습니다. 지역 선택지가 존재한다고 그 지역의 상세 공고가 반드시 제공되는 것은 아닙니다. 조회는 선택한 시도 또는 전국 최대 500건이며 일부 범위일 수 있습니다.

경력 조건과 고용형태는 여러 개 선택할 수 있으며 같은 그룹 안에서는 OR, 두 그룹 사이는 AND입니다. 신입/경력은 잡알리오의 공식 채용구분, 고용형태는 공식 코드로 분류합니다. 비정규직은 계약직 필터에 포함하며 상세 계약 조건은 원문을 확인합니다. 예시 공고의 지역·경력은 화면 체험용 가상 값입니다.

## 한국대학교육협의회 대학별 학과정보 API 연결

공식 서비스: https://www.data.go.kr/data/15158666/openapi.do

서버가 고정 주소 `https://apis.data.go.kr/B340014/SchoolMajorInfoService/getSchoolMajorInfo`를 호출합니다. `serviceKey`, `svyYr`(조사년도), `schlKrnNm`(학교명), `pageNo`, `numOfRows`를 사용하고 XML 응답을 받습니다. 키는 `.env`의 `UNIVERSITY_API_KEY`에서 읽으며 브라우저에는 설정 여부만 제공합니다.

실제 학과 선택 → 개설 대학·연도 선택 → '공식 정보 불러오기'로 사용합니다. 학교명·학과명과 학사/전문학사 학위를 확인한 응답만 표시합니다. 교육과정·관련 직업·단과대학·수업연한·학과 상태·입학정원 등 제공된 필드를 표시하고 빈 필드는 미제공으로 유지합니다. 대학 학과 API 자료를 사용자의 적성이나 지원 자격 판정으로 사용하지 않습니다.

2026년 전국 학과 검색 자료와 이 API의 제공 연도는 별개입니다. 2026년 학교 조회가 0건일 때에만 2025년으로 다시 요청하며, 화면에 요청 연도·실제 제공 연도·전환 사유를 표시합니다. 2026년 자료가 있는데 특정 학과만 찾지 못한 경우 과거 연도로 자동 대체하지 않습니다. 대학별 최대 1,000건을 확인하고 일부 조회 여부를 표시합니다. 결과는 학교·연도별로 10분간 메모리에 캐시합니다.

XML은 허용된 태그의 텍스트만 추출하며 DOCTYPE/ENTITY 응답은 거부합니다. 키·원문 오류·요청 URL을 로그로 출력하지 않고 브라우저에는 정규화한 데이터와 일반 오류만 반환합니다. 키 입력은 `register-api-keys.ps1`로 두 키를 각각 숨김 입력할 수 있고 기존 `.env`의 다른 설정을 유지합니다.
