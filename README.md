# Majorway · 전공에서 시작하는 부산 채용 탐색

Node.js 22 이상에서 별도 패키지 설치 없이 실행합니다. 로컬 실행과 Vercel 배포를 지원합니다.

서비스 주소: https://majorway.vercel.app/

GitHub Pages 주소 https://ljg9809-dotcom.github.io/majorway/ 는 현재 Pages 설정인 `main /docs`의 `docs/index.html`을 통해 Vercel 서비스로 자동 이동합니다. Pages를 루트로 바꾸는 경우에도 같은 동작을 하도록 루트 `index.html`을 함께 유지합니다. 두 위치의 `.nojekyll`은 정적 HTML을 그대로 제공합니다. 실제 화면과 서버 API는 Vercel에서 함께 제공합니다. GitHub 저장소에 API 인증키를 올리지 않습니다.

Vercel 배포는 `vercel.json`을 사용합니다. 브라우저용 세 파일만 `dist/`로 준비하고 `/api/*` 요청을 `api/index.js`의 서버 함수로 연결합니다. 서버가 참조하는 학과 JSON을 함수에 포함하며 `.env`와 원본 압축본은 배포 대상에서 제외합니다. 환경 변수 `BUSAN_API_KEY`(고용24 채용정보 키), `UNIVERSITY_API_KEY`(대학 학과정보 키)를 Vercel 프로젝트 Production 환경에 등록한 뒤 배포하세요. 선택적으로 `WORK24_API_KEY`를 등록하면 고용24 키로 우선 사용합니다. 저장소에 연결된 자동 배포를 이용하면 main 브랜치 푸시로 변경 사항이 반영됩니다.

## 1. 키 없이 미리 보기

프로젝트 폴더에서 `node server.mjs`를 실행하고 http://localhost:3000 에 접속하세요. 키가 없으면 가상 공고임을 표시하는 예시 모드로 시작합니다. 실제 API 연결 실패 시 가상 공고로 바꿔 보여주지 않습니다.

## 2. 내 터미널에서 키 등록

서버를 Ctrl+C로 종료한 후 **본인의 PowerShell 터미널**에서 실행하세요.

```powershell
cd 'C:\Users\user\Desktop\공공API서비스'
powershell -NoProfile -ExecutionPolicy Bypass -File .\register-key.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File .\start.ps1
```

등록 스크립트는 입력을 숨기며 클립보드나 명령 인자로 키를 받지 않습니다. 고용24의 채용정보 API 이용 승인을 받은 인증키를 입력하세요. 예전에 등록한 부산 공공데이터 키는 고용24에서 사용할 수 없습니다. 키는 발급받은 원문 그대로 입력합니다. `.env`의 다른 설정 및 주석을 유지하며 BUSAN_API_KEY 항목만 갱신합니다. 실행 정책 Bypass는 해당 프로세스에만 적용됩니다. 기존 BUSAN_API_KEY 환경 변수가 있다면 Node 환경 변수 우선 규칙에 따라 그 값이 사용됩니다.

키를 넣은 뒤 서버를 다시 시작하고 웹페이지를 새로고침하세요. 실제 공고 모드로 시작합니다. 설정 여부만 브라우저에 전달하며 키 값은 전달하지 않습니다. `.env`는 일반 텍스트 파일이므로 본인 계정에서 관리하고 공유하지 마세요. `.gitignore`는 Git에 새로 포함되는 것을 막으며 이미 추적 중인 파일을 자동 해제하지는 않습니다.

## 기능

- 전공 8개 분야 및 세부 전공 선택, 관련 직무 설명
- 전공·세부 전공·직무 키워드 기반 공고 분류와 발견된 연결 키워드 표시
- 공고/기관/본문 검색, 근무 형태 및 접수 중 필터, 공고 상세
- 반응형 화면, 키보드 탐색, 요청 중·실패·검색 결과 없음 상태

## 데이터 범위와 한계

출처: 한국고용정보원 고용24

공식 명세: https://www.work24.go.kr/cm/e/a/0110/selectOpenApiSvcInfo.do?fullApiSvcId=000000000000000000000000000000

API: https://www.work24.go.kr/cm/openApi/call/wk/callOpenApiSvcInfo210L01.do

서버가 authKey, callTp=L, returnType=XML, startPage=1, display=100, region=26000(부산), keyword, sortOrderBy=DESC로 호출합니다. 전공·직무 관련 키워드를 각각 최대 12개 검색하고 검색별 첫 100건을 합친 뒤 구인인증번호로 중복 제거합니다. 미확인 OR 검색 문법을 사용하지 않습니다. 최대 3개 동시 요청, 요청당 10초 제한, 검색별 5분 캐시를 적용합니다. 사용자 검색어·지역·경력·고용형태는 합친 목록에서 추가로 좁힙니다. 키워드별 전체 건수가 100건을 넘으면 일부 범위라고 안내하며 부산의 모든 공고나 마감 공고 전체를 조회했다고 주장하지 않습니다.

경력은 career, 계약기간은 empTpCd를 사용합니다. 10/11(기간의 정함이 없는 계약)은 서비스에서 정규직, 20/21(기간이 있는 계약)은 계약직으로 묶습니다. 인턴은 제목에 명시될 때만 분류하고 상세 조건은 원문으로 확인합니다. 근무형태 holidayTpNm(예: 주 5일)을 고용형태로 오인하지 않습니다. 근무지 기본·상세주소가 제공되면 구·동 필터에 사용하며 기관 주소나 접수처로 추정하지 않습니다. 두 자리 연도 날짜를 지원하고 등록일은 접수 시작일로 표시하지 않습니다. 날짜가 없더라도 명시된 채용시까지·상시 공고는 접수 중으로 분류하며 그 외 일정 미확인 공고는 별도로 표시합니다.

고용24가 해당 키워드 검색에 반환한 사실과 제목을 전공별 연결 근거로 사용합니다. 목록 응답에는 상세 직무 내용이 없으므로 본문을 만들어 표시하지 않습니다. 개별 wantedInfoUrl은 고용24·워크넷 공식 도메인만 허용하고 인증 파라미터를 제거합니다. 상세 지원 자격·모집요강은 원문에서 확인합니다. 예전 부산 공공 API는 현재 채용 검색에 사용하지 않습니다.

## 키 보호 구조

브라우저 → 로컬 `/api/jobs` → 고정된 공공 API 주소. 서버는 127.0.0.1에만 바인딩합니다. 공개 파일은 세 경로만 허용하며 `.env`, 서버 소스, 등록 스크립트를 제공하지 않습니다. 서버는 요청 URL·키·상위 오류·응답 원문을 로그에 기록하지 않습니다. 응답은 허용된 필드만 정규화하고 키와 인증 파라미터를 제거합니다. 외부 응답 HTML은 실행하지 않고 텍스트로 표시합니다. API 응답 오류 시 상세 원문 대신 일반 안내만 반환합니다. 키는 외부 공공 API의 필수 요청에만 포함됩니다.

실제 인증키는 등록하지 않은 상태로 개발했습니다. 실제 API의 현재 응답 형태·승인 상태·네트워크 연결은 키 등록 후 최종 확인이 필요합니다.

## 전국 실제 대학 학과명 검색 (2026년 자료)

교육부·한국대학교육협의회 **대학알리미 키워드별 학과정보** 공개 검색에서 대학(02)·전문대학(01), 2026년, 폐과 포함 조건으로 수집했습니다. 응답 전체 건수와 실제 수집 건수 **40,155건**이 일치함을 검사했습니다. 원본에는 학과 개편 전 폐과 기록도 있으므로 국내의 모든 현재 모집단위와 일치한다고 단정하지 않습니다. 대학알리미의 공시 범위와 시차가 적용됩니다. 대학원은 제외했습니다.

- 학과명과 대학명으로 검색하고 학교·본분교·주야간·학과 상태를 확인할 수 있습니다. 검색은 최대 30개를 표시하며 전체 검색 건수와 추가 필터 안내를 보여줍니다.

## 부산 지역·경력·고용 형태 필터

접수 중만 선택했을 때 원천 응답 전체에 접수 기간과 부산 근무지역이 확인되는 현재 공고가 없으면 전공 불일치와 구분해 안내합니다. 마감일 누락·부산 근무 여부 미확인 건수, 확인된 가장 최근 마감일, 중복 제거 건수를 표시합니다. 서버 조회 시간은 제공처 데이터 갱신일을 뜻하지 않습니다. 제목에 올해가 적혀 있어도 접수일을 추정하지 않습니다. 관련 과거 공고가 있으면 사용자가 버튼을 눌러 마감·일정 미확인 공고를 볼 수 있으며, 공식 최신 공공채용 목록 링크도 제공합니다. 공공 API의 누락·갱신 문제 자체를 보완한 최신 채용 데이터로 오해하지 않도록 표시합니다.

고용24는 키워드별 첫 100건을 조회하고 5분간 캐시합니다. 키워드별 일부 조회 여부와 중복 제거 건수를 표시합니다.

지역은 부산광역시로 한정하며 권역 → 구·군 → 동·읍·면 순서로 좁힐 수 있습니다. 부산 근무로 확인할 수 없는 빈 지역과 타 시도 공고는 제외합니다. 구·군 단독 표기는 부산 전용 제공기관의 범위 안에서 해석합니다.

- 동부산권: 해운대구·수영구·기장군
- 중부산권: 중구·서구·동구·영도구·부산진구·동래구·남구·금정구·연제구
- 서부산권: 강서구·북구·사상구·사하구

권역은 행정구역이 아닌 서비스의 탐색용 묶음입니다. 부산연구원 연구자료의 3권역 구분을 참고했습니다: https://data.bdi.re.kr/PDF/View.do?dir=report&path=RPT_00000000001&savename=20250715153603_87757

동 목록은 전체 법정동·행정동 사전이 아니라 **현재 조회 범위의 공고 고용24 근무지역·근무지 주소에 실제로 적힌 동·읍·면**입니다. 행정동과 법정동을 자동 변환하거나 기관 주소·접수처·본문의 주소로 근무지를 추정하지 않습니다. 여러 근무지가 있으면 각 구·동의 쌍을 유지합니다. 상위 지역을 바꾸면 하위 선택을 초기화합니다. 데이터가 없는 구·동은 결과가 없을 수 있으며 동 목록은 근무지역 표기에 따라 표시됩니다.

부산 전체로만 적힌 공고는 특정 권역·구·동에 임의 배정하지 않습니다. 상세 지역을 선택할 때는 기본적으로 제외하며, '상세 지역 미제공 공고도 포함'을 켜면 알려진 상위 지역이 충돌하지 않는 공고만 함께 표시합니다. 부산 근무 여부 자체가 미확인인 공고와 명시된 다른 구·군은 이 옵션으로 포함하지 않습니다.

경력 조건(신입·경력·경력무관·정보 미제공)과 고용 형태(인턴·계약직/기간제·정규직·공무직·무기계약직·임기제·정보 미제공)를 각각 여러 개 선택할 수 있습니다. 같은 그룹 안에서는 OR, 두 그룹 사이는 AND입니다. 경력무관 공고는 신입·경력 선택에도 포함합니다. 기간제는 계약직으로 묶고 무기계약직은 별도로 표시합니다. 경력증명서 제출이나 경력 우대만으로 경력 필수로 판정하지 않으며 인턴이라는 이유만으로 신입으로 판정하지 않습니다. 정규직 전환형 인턴을 정규직 공고로 분류하지 않습니다.

고용24의 경력 필드를 우선 사용하고 고용형태 코드가 없으면 제목에 명시된 문구로 보수적으로 분류합니다. 애매한 공고는 정보 미제공으로 유지하며 최종 지원 자격은 원문을 확인해야 합니다. 예시 공고의 지역·경력은 필터 체험용 가상 값입니다. 실제 API 연결은 고용24 키 등록 후 검증이 필요합니다.

## 한국대학교육협의회 대학별 학과정보 API 연결

공식 서비스: https://www.data.go.kr/data/15158666/openapi.do

서버가 고정 주소 `https://apis.data.go.kr/B340014/SchoolMajorInfoService/getSchoolMajorInfo`를 호출합니다. `serviceKey`, `svyYr`(조사년도), `schlKrnNm`(학교명), `pageNo`, `numOfRows`를 사용하고 XML 응답을 받습니다. 키는 `.env`의 `UNIVERSITY_API_KEY`에서 읽으며 브라우저에는 설정 여부만 제공합니다.

실제 학과 선택 → 개설 대학·연도 선택 → '공식 정보 불러오기'로 사용합니다. 학교명·학과명과 학사/전문학사 학위를 확인한 응답만 표시합니다. 교육과정·관련 직업·단과대학·수업연한·학과 상태·입학정원 등 제공된 필드를 표시하고 빈 필드는 미제공으로 유지합니다. 대학 학과 API 자료를 사용자의 적성이나 지원 자격 판정으로 사용하지 않습니다.

2026년 전국 학과 검색 자료와 이 API의 제공 연도는 별개입니다. 2026년 학교 조회가 0건일 때에만 2025년으로 다시 요청하며, 화면에 요청 연도·실제 제공 연도·전환 사유를 표시합니다. 2026년 자료가 있는데 특정 학과만 찾지 못한 경우 과거 연도로 자동 대체하지 않습니다. 대학별 최대 1,000건을 확인하고 일부 조회 여부를 표시합니다. 결과는 학교·연도별로 10분간 메모리에 캐시합니다.

XML은 허용된 태그의 텍스트만 추출하며 DOCTYPE/ENTITY 응답은 거부합니다. 키·원문 오류·요청 URL을 로그로 출력하지 않고 브라우저에는 정규화한 데이터와 일반 오류만 반환합니다. 키 입력은 `register-api-keys.ps1`로 두 키를 각각 숨김 입력할 수 있고 기존 `.env`의 다른 설정을 유지합니다.
